## What v0.1.0 is missing

These are referenced by name in templates/CLAUDE.md and rules/agent-routing.md but do not exist as skill folders:

1. `skills/brainstorm/` - forces success-criteria definition before any new work
2. `skills/plan/` - breaks work into tasks, each with success criteria and a "must not break" list
3. `skills/execute/` - runs a plan with baseline capture and regression gates at every step, orchestrates explorer -> implementer -> tester -> reviewer
4. `skills/review-gate/` - a 60-second check, not a full review, with scope-creep detection (flag files changed outside the stated task)
5. `skills/debug/` - debugger investigates, implementer fixes, explicit re-enter-debug-cycle instruction if the fix introduces new failures
6. `skills/handoff/` - packages context for another agent or session. Portable anchors only (repo-relative paths, symbols, module names, no absolute paths). Receiver assesses before acting. Includes baseline and blast radius when available.

The routing table in rules/agent-routing.md and the Workflow section in templates/CLAUDE.md both promise these commands. Right now `/brainstorm` and `/plan` and `/execute` do nothing.
